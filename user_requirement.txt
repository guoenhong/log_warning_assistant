# log warning assistant

## 1.1 输入（Input）
- 用户自然语言问题（例如：“最近 1 小时 5xx 异常升高的主要原因是什么？”）；
- 日志文件路径（可使用课程样例日志或学员自带脱敏日志）；
- 可选参数（时间范围、关键词、top_n）；
- 可选知识文本（运维 FAQ / 历史故障摘要，作为轻量检索材料）。

## 1.2 功能（Function）
助手至少需要具备以下能力：
- 能根据用户问题选择合适的工具函数；
- 能执行日志统计与错误模式检索等基础工具；
- 能将工具结果回填给 LLM，生成结构化分析报告；
- 能在信息不足时明确说明缺失数据，不编造事实；
- 能记录关键调用日志（调用了哪个工具、参数是什么、是否成功）。

## 1.3 输出（Output）
输出采用固定结构，建议至少包含：
1. 结论（发生了什么）；
2. 关键数据（状态码分布、Top IP、关键时间窗口等）；
3. 建议（优先排查步骤）。
4. 当无法得出结论时，输出“信息不足”，并给出下一步需要补充的数据项。
